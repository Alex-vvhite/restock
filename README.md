# Первый прототип «Учёт хозтоваров»

Реализован первый рабочий поток: вход пользователя → выбор места хранения → поиск товара → поступление/списание → серверный пересчёт остатка.

## Состав
- `app/` — Android-клиент на Kotlin и Jetpack Compose.
- `server/` — API-сервер на Node.js; при работе с PostgreSQL используется пакет `pg`.
- `server/data/seed.json` — 60 товаров из присланной таблицы с подтверждёнными стартовыми остатками и рекомендуемыми запасами. Неполная строка «Лешик пупок» исключена из каталога; она отражена в `importWarnings`.
- Локально при первом запуске seed копируется в `server/data/state.json`; последующие операции и история хранятся там же. В облаке при наличии `DATABASE_URL` сервер использует PostgreSQL. Команда `npm run import:state` переносит JSON-состояние в пустую базу один раз.

## Запуск API на компьютере
Требуется Node.js 20 или новее.

В PowerShell из папки `restock-android`:

```powershell
$env:APP_USERS_JSON='[{"username":"manager","password":"замените-на-свой-пароль","displayName":"Менеджер","role":"manager"},{"username":"staff","password":"замените-на-свой-пароль","displayName":"Сотрудник","role":"operator"},{"username":"viewer","password":"замените-на-свой-пароль","displayName":"Просмотр","role":"viewer"}]'
cd server
node index.mjs
```

Роли `manager` и `operator` могут проводить поступления и списания; `viewer` может только просматривать остатки. Для каждого человека задаётся отдельная учётная запись; автор и время записываются в журнал движений.

## Android-клиент
Откройте `restock-android` в Android Studio. Для Android Emulator адрес API по умолчанию — `http://10.0.2.2:3000`. На странице входа можно указать другой адрес сервера. Для физического телефона укажите сетевой адрес компьютера, на котором запущен API.

В этом прототипе включён HTTP для локальной разработки. При размещении сервера для сотрудников подключите HTTPS и отключите cleartext traffic в манифесте Android.

## Ограничения первого шага
Локальное JSON-хранилище подходит для прототипирования. Для облака используйте PostgreSQL и HTTPS; состояние нельзя хранить только в файловой системе контейнера. Debug APK успешно собран командой `assembleDebug`. Готовый файл: `outputs/restock-debug.apk`. Для дальнейшей сборки откройте проект в Android Studio и установите Android SDK Platform 35.
